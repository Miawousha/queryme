supplier-data-mapping est une boîte à outils d'agents IA pour piloter le cycle de vie du jumeau numérique chez ION-Altergo — classifier les signaux fournisseurs, les mapper sur des définitions de capteurs et déployer les instances de jumeaux. Livre un ensemble de runbooks d'agents et des documents de standard couvrant classes de signaux, conventions de nommage et conception des modèles de capteurs, pour que humains et agents partagent une seule source de vérité. Développement actif, produit interne.
