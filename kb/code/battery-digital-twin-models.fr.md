battery-digital-twin-models est un framework Python en deux couches pour livrer des modèles batterie en jumeau numérique sur la plateforme Altergo. Une couche (`altergo_interface/`) gère l'intégration plateforme, l'autre (`models/`) accueille les implémentations scientifiques pures, ce qui permet d'écrire des algorithmes sans toucher à la plomberie. Architecture de référence open-source extraite de travaux internes.
