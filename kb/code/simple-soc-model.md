simple_soc_model is a minimal State-of-Charge function on the Altergo function-template scaffold, kept tiny so new model authors can read it end to end. Demonstrates the entrypoint shape, configuration JSON, and validation JSON the platform expects, with just enough SoC logic to be a real model. Reference example for the boilerplate.
