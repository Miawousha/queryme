Sirene is a lightweight Tauri 2 desktop app for editing Mermaid diagrams with a live preview. Split-pane CodeMirror 6 editor on the left, zoomable SVG preview on the right; ships as a ~3 MB installer with no bundled browser. Built with React and shadcn/ui — multiple tabs, eight diagram templates, dark/light themes, and copy-as-PNG/SVG for pasting into docs.
