spritz-modern est la réécriture moderne du gestionnaire de tâches Altergo spritz, qui troque la stack JS d'origine pour React, TypeScript, Redux Toolkit, Styled Components, React Spring et Vite. Ajoute un système de skinning par composants qui rend l'ajout et la personnalisation de thèmes triviaux. Suite interne de `spritz` ; supplantée par la version personnelle en SvelteKit.
