cell-imbalance est un modèle Python qui quantifie le déséquilibre entre cellules au sein d'un pack batterie, échafaudé sur le model boilerplate d'Altergo pour se déployer directement contre des assets jumeaux en production. Détecte la dérive en tension, capacité ou température entre cellules et fait remonter les pires écarts pour les alarmes et l'équilibrage en aval. Dépôt de modèle interne.
