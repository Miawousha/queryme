supplier-data-mapping is an AI-agent toolkit for digital-twin lifecycle management at ION-Altergo — classifying supplier signals, mapping them to sensor definitions, and deploying twin instances. Ships a set of agent runbooks plus standards documents covering signal classes, sensor naming conventions, and sensor-model design, so humans and agents share a single source of truth. Active development, internal product.
