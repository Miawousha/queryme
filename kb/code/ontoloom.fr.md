Next.js 16 app that captures professional knowledge as typed "artifacts" (skills, values, preferences) stored as GitHub-backed markdown files and indexed in Supabase with pgvector. Provides a force-directed graph UI, an MCP server, and LLM-assisted authoring via Claude/OpenAI. Workspaces scope artifacts across personal and company contexts.
