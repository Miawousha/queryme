bess_control_sim is a Python simulator for Battery Energy Storage System control algorithms. Pairs a BESS model and a sim runner with a Dash app, so control strategies can be exercised, visualised, and compared interactively. Internal sandbox for iterating on control logic before it touches production EMS code.
