polypress is a Next.js 16 + Drizzle/Postgres app that runs automated content ingestion, tagging, brief generation, and article drafting on a cron-driven pipeline. It combines Anthropic Claude (via the AI SDK), Tavily search, and Supabase for storage and auth into a single agentic loop. Built as a personal media-monitoring and writing tool.
