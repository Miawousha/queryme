string-theory is a quest-based guitar-skill platform that turns scattered practice into a clear, unlockable path across six domains: time, technique, fretboard, harmony, ear, and improv. Each exercise has an explicit "done when" checkpoint and feeds into XP and quest progression; 25-minute sessions stack 2–4 complementary micro-skills. Built with Next.js 16, shadcn/ui, Prisma, and NextAuth.js.
