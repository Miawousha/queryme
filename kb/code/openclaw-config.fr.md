openclaw-config est le répertoire de configuration et d'état d'un runtime d'agent personnel tournant en continu — agents, cron, appareils, identité, mémoire, complétions, le tout en fichiers versionnés. Ce n'est pas un codebase déployable ; c'est le substrat sur lequel l'agent s'exécute. Privé, modifié en continu au fil de l'apprentissage de l'agent.
