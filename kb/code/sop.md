sop is the State-of-Power model on the Altergo digital-twin platform — estimates the maximum power the pack can sustain over a given horizon for charge and discharge, given current state and limits. Built on the model-boilerplate scaffold so it shares wiring with the rest of the State-of-X fleet (`soc`, `soh`, `soe`, `sof`). Internal model repo.
