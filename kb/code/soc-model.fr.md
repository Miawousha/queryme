soc-model est une implémentation Python d'un estimateur State-of-Charge batterie. Prend en entrée des données capteur (tension, courant, température) et une spec de modèle de cellule, et renvoie les estimations de SoC via le SDK Altergo pour stockage et consommation en aval. Dépôt de modèle interne câblé dans le flux de données de la plateforme.
