cell-imbalance is a Python model that quantifies cell-to-cell imbalance inside a battery pack, scaffolded on the Altergo model boilerplate so it deploys directly against live twin assets. Detects drift in voltage, capacity, or temperature across cells and surfaces the worst offenders for downstream alarms and balancing decisions. Internal model repo.
