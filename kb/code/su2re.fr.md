Cross-platform Electron desktop app for transcribing audio with OpenAI Whisper (via faster-whisper, CPU or CUDA). Adds speaker diarization, live push-to-talk recording, AI-driven text cleanup, and calendar-event extraction. JavaScript front end paired with a Python transcription backend.
