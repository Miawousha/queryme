rtbm (Real-Time Battery Modeling) is a minimal Altergo-integrated reference app showing how to bootstrap a battery model from local CSV power profiles and a simspec file. Wires the Altergo SDK to a `models/rtbm/` implementation and runs through `entrypoint.py`; configuration is held in `altergo-settings.json` and `dev-parameters.json`. Used as the canonical starting point for new battery models on the platform.
