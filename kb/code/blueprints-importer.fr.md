blueprints_importer est un utilitaire Python pour importer des blueprints dans la plateforme IoT Altergo, en complément de `blueprint-creator` côté rédaction. Gère le chemin d'import en masse : lit un jeu de définitions de blueprints et les pousse via l'API plateforme avec la bonne hiérarchie et le câblage de paramètres. Outillage interne.
