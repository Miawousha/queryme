Next.js 16 + Supabase application backing OPUS, a scientific publication platform that treats every paper as a structured, typed, citable object rather than a PDF. Integrates Anthropic Claude for assisted review/editing and ships markdown+KaTeX rendering, diffs, and seed scripts. Early-stage infrastructure for the journal.
