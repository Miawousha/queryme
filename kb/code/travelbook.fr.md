travelbook est l'app web interne d'ION-Altergo pour planifier les déplacements ingénieurs sur site, suivre les dépenses et générer les rapports clients. Construit avec Next.js 15, TypeScript et shadcn/ui sur une surface inspirée de Linear ; Google OAuth verrouille les vues équipe et le suivi multi-devises. Dépôt public de l'organisation, utilisé par l'équipe ingénierie pour coordonner le terrain.
