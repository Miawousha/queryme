blueprints_importer is a Python utility for importing blueprints into the Altergo IoT platform, complementing `blueprint-creator` on the authoring side. Handles the bulk-load path: read a set of blueprint definitions and push them through the platform API with the right hierarchy and parameter wiring. Internal developer tooling.
