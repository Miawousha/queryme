tsdb-benchmark is a small benchmark suite comparing time-series databases (QuestDB and ClickHouse) on the kind of sensor-data ingestion pattern the platform actually runs. Schemas, Docker setup, and CSV-ingest commands sit alongside the result write-ups. Internal due-diligence repo used to pick a TSDB backend for the Altergo data plane.
