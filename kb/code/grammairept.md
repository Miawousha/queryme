Educational SvelteKit web app for teaching French grammar to children aged 8 to 13. Combines a Photoshop-style training mode (apply grammar tools to marked-up text) with a quest mode where pupils fight grammatical monsters to progress. Built on a custom SyMark markup that encodes word natures, syntactic functions, and grammatical groups.
