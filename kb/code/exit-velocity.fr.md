exit_velocity est une application Next.js 15 axée sur la confidentialité qui permet à des fondateurs d'explorer des options de sortie via un formulaire d'admission pseudonyme à usage unique. Aucun tracking, aucun brouillon enregistré, aucun cookie — chaque soumission est relue manuellement. Construit avec TypeScript, Tailwind, shadcn/ui, Vercel Postgres et Resend pour l'email ; déployé sur exitvelocity.me comme canal d'entrée privé.
