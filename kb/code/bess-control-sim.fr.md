bess_control_sim est un simulateur Python pour les algorithmes de contrôle des Battery Energy Storage Systems. Couple un modèle de BESS et un runner de simulation à une app Dash, pour itérer sur les stratégies de contrôle de manière visuelle et interactive. Bac à sable interne pour expérimenter la logique de contrôle avant qu'elle ne touche le code EMS de production.
