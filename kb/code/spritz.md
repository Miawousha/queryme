spritz is the original Altergo task-manager web app, built in plain HTML/CSS/JS with GSAP for animations and Firebase for real-time data and hosting. Markdown tasks, left-click to toggle, right-click for animated deletion, "gooey" effects when tasks idle too long, shareable real-time collab links. The starting point for the later `spritz-modern` rewrite and the personal SvelteKit continuation.
