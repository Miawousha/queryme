hydrogen is a Python simulation of a hydrogen plant, runnable in three modes: legacy only, Lair only, or both side-by-side for comparison. Configuration-file driven (`dev-parameters.json`) so the same plant can be exercised under different parameter sets without code edits. Internal R&D tool for cross-checking simulation engines on hydrogen production.
