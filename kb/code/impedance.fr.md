impedance est un modèle Python d'impédance cellule, échafaudé sur le model boilerplate Altergo pour se déployer contre des assets jumeaux en production avec l'intégration SDK déjà câblée. Le boilerplate s'occupe de la plomberie plateforme, l'estimateur d'impédance vit dans `models/`. Dépôt de modèle interne.
