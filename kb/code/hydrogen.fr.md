hydrogen est une simulation Python d'usine hydrogène, exécutable en trois modes : legacy seul, Lair seul, ou les deux en parallèle pour comparaison. Pilotée par fichier de configuration (`dev-parameters.json`) afin d'exécuter la même usine sous différents jeux de paramètres sans toucher au code. Outil R&D interne pour comparer des moteurs de simulation sur la production d'hydrogène.
